Help

Loading games

Open Cloud and choose a game from the Games list. The server must provide the game catalog and files.

Cloud games are streamed in small parts as needed, so the entire disc does not need to fit in browser memory.

This keeps memory usage low enough to play larger games on Xbox, where Microsoft Edge has roughly a 1 GB memory limit.

For local games, choose the CUE file and all BIN files it references.

Upload your own 512 KiB BIOS from Menu, or load games/bios.bin from the configured server. The BIOS is used the next time a game starts.

Keyboard controls

  • D-pad: Arrow Keys
  • Select: C
  • Start: Enter
  • L1: W
  • R1: R
  • L2: E
  • R2: T
  • Triangle: D
  • Circle: X
  • Cross: Z
  • Square: S

Mobile controls

Use the virtual stick and face buttons. Touch controls support multiple buttons at once.

On Xbox, use the browser's Game Controls command to enable or disable controller capture.

Save data

Memory cards are saved locally. The Menu contains save-state and memory-card tools; Cloud contains optional server upload and download actions.
